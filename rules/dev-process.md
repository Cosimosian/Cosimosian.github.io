# 风景园林 × 软件工程 ×AI 工程三段叙事求职官网｜软件工程级落地全流程（AI 辅助开发・高内聚低耦合・可扩展架构・GitHub Pages 部署）

## 一、核心设计原则与工程目标

以**叙事型单页应用（SPA）** 为核心架构，严格遵循「高内聚、低耦合、可扩展、易维护」软件工程原则，全程 AI 辅助分层次开发，用户主导设计校验与进度管控：



1. **解耦分层**：视觉主题、履历数据、交互逻辑、页面布局完全隔离，修改任意模块不影响其他模块

2. **扩展优先**：后续新增履历项目、人生阶段无需重构核心代码，仅需补充数据或新增主题样式文件

3. **TA 美术工程化**：将南法园林 / 千禧街机 / AI 未来三套视觉主题封装为可切换标准管线，统一复用全局交互逻辑

4. **触控适配兼容**：针对移动端优化拖拽交互、简化高消耗视觉材质、调整布局间距

5. **静态部署适配**：无后端依赖，完全适配 GitHub Pages 静态托管环境



***

## 二、技术架构选型（AI 友好・轻量解耦・适配部署）

采用原生模块化前端架构，避免过重框架依赖，降低 AI 生成与后续维护门槛，所有资源按需分层加载：



| 分层      | 技术方案                   | 作用                                  | 解耦逻辑                        |
| ------- | ---------------------- | ----------------------------------- | --------------------------- |
| **数据层** | 独立 JSON 静态文件           | 存储所有履历内容（阶段标题、项目描述、素材链接、标签）         | 完全与视觉、交互隔离，新增内容仅修改 JSON     |
| **视觉层** | 原生 CSS 变量 + 独立主题类      | 封装三套完整 TA 视觉主题，通过`data-theme`属性全局切换 | 主题样式与布局代码完全隔离，单独维护主题 CSS 文件 |
| **结构层** | 语义化 HTML5 + 独立组件模板     | 通用页面布局、履历卡片模板、时间轴固定锚点结构             | 模板不嵌入业务逻辑，仅通过 JS 导入数据渲染     |
| **交互层** | 原生 TypeScript（或 JS）工具类 | 封装拖拽时间轴、主题切换、滚动插播核心逻辑               | 独立封装为可复用工具，不依赖具体主题与数据结构     |
| **资源层** | 压缩优化后的静态素材（WebP/AVIF）  | 项目配图、主题纹理、图标资源                      | 按阶段分文件夹存储，路径由 JSON 数据统一管理   |
| **适配层** | CSS 媒体查询 + 特性检测 JS     | 移动端布局调整、高消耗滤镜性能降级                   | 自动识别设备类型，按需加载简化版视觉样式        |
| **部署层** | 原生静态资源 + GitHub Pages  | 托管所有静态文件，开启自动 CI/CD                 | 无服务器依赖，推送代码即可自动完成部署         |

### 阶段 2：工程化封装三套 TA 视觉主题（落地美术分层管线）

**目标**：将南法园林 / 千禧街机 / AI 未来三套风格封装为标准可复用 CSS 主题，严格复现技术美术分层渲染逻辑，与布局结构完全解耦

**AI 辅助生成任务**：

每套主题独立封装为 CSS 文件，通过`:root`选择器定义完整视觉变量，包含以下 4 个美术渲染层：



1. **基础色彩层**：定义背景色、文字色、强调色、阴影色、边框色，适配不同阶段色温逻辑

2. **纹理噪点层**：使用 SVG DataURL 内联生成纸张纹理、CRT 扫描线、玻璃磨砂噪点，实现无外部依赖的材质肌理

3. **组件样式层**：定义通用履历卡片、标签、时间轴游标、分区分割线的主题专属默认样式

4. **交互动效层**：定义卡片 hover 上浮、主题切换过渡、游标拖拽缩放、内容淡入淡出的统一动画曲线

   **示例主题结构**：



```
/\* garden.css 南法园林主题封装 \*/

\[data-theme="garden"] {

&#x20; /\* 基础色彩变量 \*/

&#x20; \--color-bg: #f8f3e9;

&#x20; \--color-text: #3c3228;

&#x20; \--color-accent: #a8b888;

&#x20; /\* 纹理噪点变量 \*/

&#x20; \--texture-overlay: url("data:image/svg+xml,%3Csvg...%3E%3C/svg%3E");

&#x20; /\* 组件样式变量 \*/

&#x20; \--card-radius: 16px;

&#x20; \--card-shadow: 0 8px 24px rgba(92,72,52,0.12);

&#x20; /\* 动效变量 \*/

&#x20; \--transition-theme: 0.6s cubic-bezier(0.22, 1, 0.36, 1);

}
```

**用户校验管控**：



* 依次切换三套主题，验证色彩、纹理、阴影完全匹配预设叙事风格

* hover 卡片、拖拽游标，验证交互动效流畅，无视觉重影、卡顿

* 确认主题切换时全局文字可读性保持良好，无对比度不足问题

  **耦合保障规则**：

* 主题 CSS 文件不得直接修改布局宽高、margin、padding 全局布局属性

* 所有主题过渡动效统一使用`--transition-theme`变量，由交互层统一控制

### 阶段 4：开发核心时间轴交互逻辑（独立封装可复用工具类）

**目标**：实现底部全局拖拽时间轴，拖拽游标自动切换对应阶段的主题、内容，交互逻辑完全封装为独立工具类，不耦合业务数据与视觉样式

**AI 辅助生成任务**：

生成`TimelineController.js`独立 ES6 工具类，对外暴露标准化 API，内部实现完整交互逻辑，支持配置化定制：



1. 核心功能：

* 响应鼠标 / 触屏拖拽事件，实时同步游标位置

* 按配置比例分区，自动匹配当前游标所在的人生阶段区间

* 触发主题切换事件、更新履历内容渲染锚点

* 支持点击时间轴任意位置跳转对应阶段，游标自动吸附到分区中点

1. 标准化 API 设计：



```
const timeline = new TimelineController({

&#x20; trackSelector: '.timeline-track', // 时间轴轨道选择器

&#x20; cursorSelector: '.drag-cursor', // 拖拽游标选择器

&#x20; stageSplitRatio: \[0.333, 0.666], // 阶段分割比例，与JSON配置同步

&#x20; onStageChange: (currentStage) => { // 阶段切换回调函数

&#x20;   // 外部可传入：更新主题、渲染内容、触发动效

&#x20; }

});
```



1. 适配逻辑：

* 拖拽过程中添加平滑定位插值，避免游标跟随鼠标抖动

* 移动端自动增大拖拽游标触控热区尺寸，优化触控体验

  **用户校验管控**：

- 验证鼠标拖拽、触屏滑动两种场景下游标移动、阶段切换流畅

- 快速拖拽游标，验证主题、内容无延迟切换、无 JS 报错

- 点击时间轴任意空白位置，验证游标自动吸附到对应阶段中点，内容同步更新

- 切换移动端模拟器，验证游标触控区域足够大，不会出现拖拽误触发

  **耦合保障规则**：

- 工具类内部不直接操作主题样式、渲染内容，仅通过回调函数向外传递当前阶段标识

- 工具类不硬编码任何时间轴阶段数量、分割比例，所有配置参数由外部传入，便于后续新增阶段
