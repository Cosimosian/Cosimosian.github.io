| 参数 | 状态 | 值 | 来源 |

## 7. 设备检测

```typescript
// 逻辑断点
const BREAKPOINTS = {
  mobile:  768,    // < 768px：手机
  tablet:  1024,   // 768-1023px：平板
  desktop: 1200,   // > 1200px：大桌面
};

// 设备类型检测
function getCurrentDevice(): 'mobile' | 'tablet' | 'desktop' {
  const width = window.innerWidth;
  if (width <= 768) return 'mobile';
  if (width <= 1200) return 'tablet';
  return 'desktop';
}
```
