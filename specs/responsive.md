# 响应式设计规格

> 本文档定义响应式设计的**硬性布局规则**和设备差异。视觉降级细节见 `specs/themes.md`。
>
> 核心策略：**桌面优先，移动端降级**。核心魅力（材质、粒子、大画幅地图）在桌面端完整展现，
> 移动端追求信息清晰、操作顺滑、氛围不丢失。

---

## 1. 逻辑断点

| 断点 | 设备 | 布局策略 |
|------|------|---------|
| `> 768px` | 桌面/平板 | 全屏地图背景层 + 浮动透明UI（左右双面板 + 底部卡尺时间轴） |
| `< 768px` | 手机 | 单列布局、地图隐藏、粒子减半、模糊关闭（移动端不做改动） |

---

## 2. 布局结构（桌面端 >768px）

全屏地图背景 + 浮动透明UI覆盖层：

```
┌──────────────────────────────────────────────┐
│ 全屏Canvas地图背景层（z-index: 0）            │
│ ┌─────────────────────┐                      │
│ │   中国地图（居中）    │                      │
│ │   ★ 城市标记         │                      │
│ └─────────────────────┘                      │
├─────────────── UI覆盖层（z-index: 1）─────────┤
│                                              │
│  [透明叠底头部]                                │
│  阶段01｜读懂季节，读懂种子...                   │
│                                              │
│  ┌──左展示面板──┐        ┌──右导航面板──┐   │
│  │ 项目卡片(28vw)│        │ 项目列表(18vw)│   │
│  │ 详情/标签     │        │ 主题按钮/时间轴│   │
│  └──────────────┘        └──────────────┘   │
│                                              │
│  ┌──────────────────────────────────────┐   │
│  │  卡尺时间轴（7vh）                     │   │
│  │  2016──┬──┬──2021.9──┬──2024.7─2026  │   │
│  │        ▲                             │   │
│  │     卡尺滑块                          │   │
│  └──────────────────────────────────────┘   │
└──────────────────────────────────────────────┘
```

| 区域 | 定位 | 尺寸 |
|------|------|------|
| 地图背景 | `position: fixed; inset: 0; z-index: 0` | 100vw × 100vh |
| 头部 | `position: absolute; top: 0; left: 0; right: 0` | 自动高度（透明浮动） |
| 左展示面板 | `position: absolute; left: 3vw; top: 0; bottom: 0` | `width: 28vw`（撑满内容区） |
| 右导航面板 | `position: absolute; right: 3vw; top: 0` | `width: 18vw; max-height: 100%` |
| 右下经历时间轴 | `position: absolute; right: 3vw; bottom: 7vh+72px` | `width: 18vw; max-height: 30vh` |
| 右下经纬度 | `position: absolute; right: 3vw; bottom: 7vh+46px` | 自动尺寸 |
| 卡尺时间轴 | `position: absolute; bottom: 0; left: 0; right: 0` | `height: 7vh`，轨道宽 88% |
| 地图投影 | 中心 `0.38w × 0.38h` | `scale = min(min(w,h)×0.85, 900)` |

> **🔒 尺寸锁定规则（2026-08 确立）**：上表为已确认尺寸，任何调整必须：
> 1. 先修改本表并说明原因；
> 2. 经用户明确批准后才能改动代码；
> 3. 禁止在功能开发中"顺手"调整已定尺寸（曾发生 `min(18vw,280px)` 未批准改动导致导航面板变窄的问题）。

### 桌面端（>768px）
```

├── 中国地图 Canvas（居中，含城市标记点）
```

## 5. 组件响应式规则

### 地图（ChinaMap — 全屏背景层）
| 规则 | 桌面端 | 移动端 |
|------|--------|--------|
| 定位 | `position: fixed; inset: 0; z-index: 0` | `display: none` |
| Canvas尺寸 | 100vw × 100vh，ResizeObserver 动态重算 | N/A |
| 中国地图位置 | 居中显示，周边地理信息在边角 | N/A |
| 城市标记 | 在地图上层渲染，后续具体填充位置 | N/A |

### 面板（ConsolePanel / DisplayPanel）
| 规则 | 桌面端 | 移动端 |
|------|--------|--------|
| 布局 | 左右双面板（28% + 48%） | N/A（移动端使用信息流卡片） |
| 背景 | 透明叠底 + 细线边框 + backdrop-filter | N/A |
| 文字 | text-shadow 保证地图背景上可读 | N/A |
| 交互 | 左面板点击→右面板更新内容 | N/A |

### 时间轴（Timeline — 卡尺风格）
| 规则 | 桌面端 | 移动端 |
|------|--------|--------|
| 高度 | 7vh | 15vh |
| 轨道 | 细线（1-2px） | 保持 |
| 游标 | 卡尺滑动块（3×24px视觉，24×80px触控） | 同左 |
| 刻度 | 2016-2026，年大刻度+月小刻度 | 保持 |
| 固定定位 | ✅ | ✅ |

### 模态窗（Modal）
| 规则 | 桌面端 | 移动端 |
|------|--------|--------|
| 宽度 | 60% | 95% |
| 高度 | 自适应（最大80vh） | 80% |
| 滚动 | 无 | `overflow-y: auto`（内容过多时） |

## 6. 性能降级策略

移动端自动执行以下降级（通过在 `<body>` 添加 `.is-mobile` 类触发）：

1. 关闭 `backdrop-filter` 模糊效果
2. 粒子数量降至 150
3. 关闭 SVG 纹理叠加（替换为纯色背景）
4. 减少 `box-shadow` 模糊半径
5. 关闭游标拖拽缩放效果
6. 动画时长减半
7. 图片懒加载（`IntersectionObserver`）
8. 简化字体渲染（`-webkit-font-smoothing: antialiased`）

```css
body.is-mobile .glass-morphism {
  backdrop-filter: none;
  background: rgba(255, 255, 255, 0.95);
}

body.is-mobile .project-card-overlay {
  animation-duration: 0.3s;
}

/* prefers-reduced-motion */
@media (prefers-reduced-motion: reduce) {
  .project-card-overlay,
  .timeline-section {
    animation: none;
  }
}
```

## 7. 双端互斥元素的 CSS 规则

桌面优先策略下，CSS 基线（无媒体查询包裹）为桌面端样式。如果某个元素在桌面端和移动端有不同的显示/隐藏需求，必须显式处理：

| 元素 | 基线（桌面端） | 移动端 `@media (max-width:768px)` |
|------|--------------|----------------------------------|
| 地图 Canvas | 显示（`display:block`） | `display:none` |
| 桌面面板（console/display） | 显示 | `display:none` |
| 移动端信息流 | **`display:none`**（基线必须显式隐藏） | `display:flex` |

**规则**：任何仅在移动端显示的元素，必须在基线 CSS 中显式设置 `display:none`，否则浏览器会给 `<div>` 默认的 `display:block`，导致桌面端多余渲染。

## 9. 桌面分档响应式策略（202609 确立）

> **🔒 与 §2 尺寸锁定规则同级**：本节参数调整必须先改本表并经用户批准。
> 目标：覆盖 2026 常见桌面设备与窗口化场景（1366×768 ~ 3440×1440 + 半屏/矮窗）。

### 9.1 断点分档

| 档位 | 触发 | 策略 |
|------|------|------|
| S（压缩档） | 769–1280px | 保持 vw 比例 + clamp 下限保护（平板竖屏/半屏窗口/老笔记本）；面板纵横比封顶防竖条（§10.3） |
| M（基线档） | 1281–1920px | 现状比例，零变化（主流 1920×1080） |
| L（放大档，20260918 确立） | 1921–2400px | 面板 clamp 上限 560/360→680/430；地图 scale cap 900→1050，整幅构图等比放大 |
| XXL（居中收缩档） | >2400px | UI 容器 max-width 2200px 居中；地图 LAYOUT_CX 0.38→0.44（21:9/双屏防偏左） |
| H1（矮窗压缩） | max-height 700px | 内容区 8vh、经历时间线 22vh、弹窗头图 90px |
| H2（矮窗降级） | max-height 520px | 隐藏经历时间线与鼠标坐标 |

### 9.2 移动端 gate 阈值

`mobile-gate` 触发阈值由 768px 下移至 **640px**（640 以下视为手机竖屏区间；
640–768 进入 S 档桌面压缩布局）。

### 9.3 新增设计令牌

| 令牌 | 基线 | 说明 |
|------|------|------|
| --panel-display-min/max | 300px / 560px（L 档 680px） | 左展示面板下限/上限 |
| --panel-console-min/max | 240px / 360px（L 档 430px） | 右导航面板下限/上限 |
| --fs-base（流式基准） | clamp(13px, 0.68vw, 16px) | 唯一字号定义点：1920≈13px 基线；2560→16px（+23%）；≤1366 下限 13px 兜底 |
| --fs-2xs~--fs-xl | calc(--fs-base × 0.69~2.0) | 比率阶梯（v3 层级强化：9/10/12/13/16/18/26px 基线，见 §10.2） |
| --fs-headline | clamp(14px, 2vw, 20px)（L 档上限 24px） | 头部阶段描述 |
| --content-top | 10vh（H1 8vh） | 内容区顶部偏移 |
| --exp-timeline-maxh | 30vh（S 26vh / H1 22vh / H2 0） | 经历时间线最大高 |
| --modal-edge / --modal-max-w | 18px / 1600px | 弹窗边距半径与宽度上限 |
| --ui-container-max | 2200px | XL 档 UI 容器收缩上限 |
| --map-scale-cap | 900（L 档 1050） | 地图缩放上限（js/map/chinaMap.js 经 cssVar 读取） |

> **字号规则（202609 v2 流式）**：组件字号一律引用 `--fs-*` 令牌，禁止固定 px；
> 窄屏（S 档）不再缩小字号（下限兜底可读性），压缩交给布局（面板 clamp 宽度）；
> 强风格化（换字体/字距/视觉大小）走 `--font-*`/`--ls-*`/`--fs-adjust`，不改层级比率。

### 9.4 验证矩阵

1366×768 / 1920×1080（基线零差异）/ 2560×1440 / 3440×1440 / 半屏 960×1080 /
1280×560 矮窗 / 640 边界 gate 行为。

### 9.5 同侧堆叠让位（202609 补充）

右导航面板与右下经历时间轴同侧（均 right:3vw）垂直堆叠。矮屏下导航面板需为经历
时间轴让位，避免重叠：

```css
.console-panel{
  max-height:min(100%, calc(100vh - 2*var(--timeline-h) - var(--exp-timeline-maxh) - 100px));
}
```

公式含义：视口高 − 底部时间轴×2 − 经历时间线最大高 − 100px（content 底边 4px +
时间线 offset 72px + 24px 安全间距）。基线档（M）内容未超限时不受影响，仅在矮屏
（如 iPad 横屏 768 高）触发滚动。

## 10. beta 测试修复批次（20260918 确立）

> 来源：beta 测试反馈 + 产品化评审。本节改动全部登记于 🔒 锁定规则之下。

### 10.1 时间线对齐 + 低分辨率横向滚动

- 卡尺时间轴由「88% 居中」改为 **`margin:0 3vw` 贯穿内容区全宽**：左缘对齐左展示面板（3vw）、右缘对齐右导航面板（97vw），消除"右缩"
- 新增滚动容器 `.caliper-scroll`：内容最小宽 **900px**（≈88px/年，月刻度可读）；窄窗可横向滚动
- **无滚动条**：`scrollbar-width:none` + `::-webkit-scrollbar{display:none}`
- 滚轮映射：`wheel` 事件 `deltaY → scrollLeft`（`passive:false`，仅当存在横向溢出时拦截）
- 拖拽/点击逻辑不变（`getBoundingClientRect` 天然含滚动偏移）

### 10.2 字体层级强化（v3）

| 层级 | v2 比率 | v3 比率 | 1920 基线 | 说明 |
|------|---------|---------|-----------|------|
| --fs-xl 面板/弹窗标题 | ×1.54 | **×2.0** | 20→26px | 主层级锚点 |
| --fs-h3 文章三级标题 | ×1.23 | **×1.38** | 16→18px | 文章内层级 |
| --fs-lg 弹窗正文 | ×1.15 | **×1.23** | 15→16px | 与正文拉开 |
| 其余层级 | 不变 | 不变 | 9/10/12/13 | 用 `--color-muted`/`--color-accent`/字距补对比 |

> **L 档字号定格（20260921 补充）**：`@media(min-width:1921px)` 内 `--fs-base` 直接定格 **16px**，
> 与面板上限（680/430）和地图 cap（1050）在同一断点同步跳变并此后同步封顶，
> 消除原 1921–2353px 窗口内"面板已定格、字体仍在流式增长"的比例漂移；
> `--fs-headline` 上限在该档同步 20→24px（M 档基线保持 20px 零变化）。

### 10.3 面板纵横比封顶（竖长设备防竖条）

- display 面板：`height:min(100%, clamp宽度×1.7)` + `top:50%` 纵向居中（hover 变换合并 `translateY(-50%) scale(1.03)`）
- console 面板：`max-height` 三参数 min 并入 `clamp宽度×1.9`
- 决策记录：**移动端 gate 阈值保持 640px 不上调**——iPad 竖屏（768/820/1024）为真实用户群，布局可修复就不屏蔽；641–700px 若构图验证失败，再考虑微调至 700px（后备，未启用）

### 10.4 console 头部冻结

- `.console-panel` 改 `flex column` + `overflow:hidden`；四色点 + "项目导航"标题 `flex-shrink:0` 冻结；`#console-list` `flex:1; overflow-y:auto` 独立滚动

### 10.5 验证矩阵（本批次）

| 尺寸 | 验证点 |
|------|--------|
| 1920×1080 | 基线零差异（对齐/字号 26px 标题除外——字体 v3 有意变更） |
| 2560×1440 | L 档：面板 680/430、地图 cap 1050，构图等比 |
| 3840×2160 | L 档上限钳制不溢出；XXL 容器居中 |
| 1024×1366（竖长） | 面板纵横比封顶生效，display ≈ 287×488 居中卡片 |
| 700×1200（窄高窗） | clamp 下限 300/240 + 纵横比封顶 |
| 800×600（低分辨率） | 卡尺横向滚动、无滚动条、滚轮映射、拖拽正常 |
| 641 / 640 | gate 边界：641 显示 S 档布局，640 显示 gate |
