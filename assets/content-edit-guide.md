# 网站文字内容修改目录

> 全部文字内容位于 `index.html` 内。按下方模块定位，**只改引号内的文字，不碰引号外的结构**。
> 修改后刷新浏览器即可看到效果。

---

## 1. 页面标题（浏览器标签栏）

**位置**：`index.html` 顶部 `<head>` 内 `<title>` 标签

```html
<title>个人履历 — 环境美学 × 数字建构 × 系统工程</title>
```

---

## 2. 阶段信息（STAGES 对象）

**位置**：`<script>` 内 `const STAGES = { ... }`（约第 476 行起）

每个阶段可改的字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| `title` | 阶段副标题（暂未展示在页面，保留备用） | `'2016‑2021｜风景园林 · 落地景观与产品设计'` |
| `description` | 头部区域诗意文字 | `'自然器物之间：环境美学与人的感知联结'` |
| `experiences` | 右侧竖向时间轴条目 | 见下方格式 |
| `primaryLat` / `primaryLng` | 阶段主活动城市经纬度（地图 Level 1 标记） | `34.28, 108.07` |

**experiences 条目格式**：

```javascript
{year:2016.75, type:'教育', text:'西北农林科技大学 风景园林学士（获保研资格）'}
```

- `year`：年月数字，`2016.75` = 2016年9月（1月=0.00，2月=0.083，…，12月=0.917）
- `type`：只填 `教育` / `工作` / `实习`
- `text`：显示文字

## 3. 项目卡片（PROJECTS 数组）

**位置**：`<script>` 内 `const PROJECTS = [ ... ]`（约第 515 行起）

每条项目字段：

| 字段 | 说明 | 必填 |
|------|------|------|
| `id` | 唯一标识，不要改 | 是 |
| `title` | 项目标题 | 是 |
| `category` | 分类徽章（展示面板顶部） | 是 |
| `desc` | 简短描述（展示面板） | 是 |
| `tags` | 项目标签数组，逗号分隔 | 是 |
| `location` | 城市名（仅导航面板和地图标记用，卡片上不显示） | 是 |
| `image` | 桌面端图片路径 | 否（留 picsum 占位） |
| `mobileImage` | 移动端图片路径 | 否 |
| `stage` | 归属阶段（`garden`/`code`/`ai`），不要改 | 是 |
| `year` | 项目时间（时间轴定位用） | 是 |
| `outcome` | 成果说明（留空则不显示） | 否 |
| `link` | 项目链接（留空则不显示） | 否 |
| `lat` / `lng` | 项目城市经纬度（地图 Level 2/3 标记） | 是 |

**详细介绍模块**：卡片"项目标签"下方的"📄 详细介绍"是预留模块，待后续填充。若需填充，在 `selectProject()` 的 `display-detail-placeholder` 处（约第 720 行）把 `—— 待补充 ——` 替换为项目详情文本。

## 修改规则提醒

1. **不要改**：字段名、单引号、逗号、花括号结构
2. **year 换算**：`year = 年份 + (月份-1)/12`，例：2024年11月 = `2024.83`
3. **经纬度**：用在线地图查询城市坐标，保留两位小数
4. 改完刷新浏览器验证，卡片/时间轴/地图标记应同步变化
