# 导航结构与布局描述指南

## 📐 核心原则：四层次描述法

为了让您的个人设计想法被精准理解并转化为可扩展的代码架构，请按这四个层次描述：

```
第0层：网页结构确认（页面数量与关系）
  ↓
第1层：整体布局结构（框架）
  ↓
第2层：模块组成与关系（组件）
  ↓
第3层：视觉细节与交互（样式）
```

---

## 🌐 第0层：网页结构确认（架构级规则）

### **为什么这是第一步？**

网页结构决定了：
- 📁 文件组织方式
- 🔄 页面之间的跳转逻辑
- 🛣️ URL路径设计
- ⚙️ 是否需要路由系统
- 🎯 SEO和可访问性策略

**这是架构级规则，必须在开始开发前确认，后期修改成本极高。**

---

### **描述方式：页面关系图**

页面结构：混合结构

load.html(加载页)
index.html（核心导航页）
├── 头部区域
├── 内容区域（阶段切换），点击项目卡片，弹出内联无跳转项目详情模态窗，点击“esc”窗口收起
└── 时间轴区域
    └── /about（简历页）

URL结构：
- 首页和加载页和项目页：/
- 简历页：/about

特点：
- 核心体验为单页沉浸式
- 详情页可选扩展
- 灵活性高
- 后期可渐进式添加页面
```

---

### **需要确认的关键问题**

#### **1. 页面数量**
```
[ ] 单页（只有首页）
[ ] 多页（首页+详情页+关于页）
[-] 混合（首页为核心，详情页可选扩展）
[ ] 其他：_____________________
```

#### **2. 是否需要项目详情页**
```
[ ] 不需要（首页卡片展示足够）
[ ] 需要（点击卡片跳转到详情页）
[ ] 后期扩展（先不预留，后期再说）
[ ] 先预留接口（预先做好架构准备）
[-] 其他：首页点击项目卡片，弹出内联无跳转项目详情模态窗
```

#### **3. 是否需要关于页**
```
[ ] 不需要（首页已包含个人信息）
[-] 需要（独立的关于页展示更多信息）
[ ] 后期扩展
```

---

### **为什么必须在开始前确认？**

#### **❌ 如果后期想从单页改为多页：**
```
成本估算：
- 重构HTML结构：2-3天
- 添加路由系统：1-2天
- 调整CSS样式：1天
- 测试所有页面：1天
总计：5-7天返工
```

#### **❌ 如果后期想从多页改为单页：**
```
成本估算：
- 合并页面内容：1-2天
- 重写交互逻辑：2-3天
- 调整SEO策略：1天
- 测试整体体验：1天
总计：5-7天返工
```

#### **✅ 如果一开始就确认好：**
```
开发流程：
1. 按确认的结构搭建架构
2. 实现核心功能
3. 完成后无需重构
总计：0天返工
```

描述每个组件的**行为和样式特征**：

#### **示例：时间轴游标的交互规则**
```
【组件】拖拽游标（DragCursor）

【视觉特征】
- 默认状态：圆形，宽度40px，高度40px
- 位置：在轨道上水平移动
- 颜色：跟随当前主题的强调色

【交互行为】
- 鼠标按下：游标放大到1.2倍，显示阴影
- 拖拽过程：实时跟随鼠标X轴位置
- 拖拽释放：自动吸附到最近阶段的中点
- 吸附距离：50px内的区间自动吸附

【动画效果】
- 位置变化：transition 0.3s ease-out
- 缩放：transition 0.2s ease-in-out
- 颜色变化：跟随主题切换过渡

【移动端适配】
- 触控热区：80px × 60px（比可视区域大）
- 拖拽灵敏度：手指移动1.5px，游标移动1px
- 动效降级：禁用缩放效果，只移动
```

class TimelineController {
  constructor(options) {
    this.adsorptionDistance = 50; // 您指定的吸附距离
