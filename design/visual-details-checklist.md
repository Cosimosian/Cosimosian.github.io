### 2️⃣ 中国地图的三种渲染风格

#### 【风景园林阶段 - 水彩手绘风格】

```
【已填写的方案】
参考风格：水彩画 + 纸张质感 + 温暖色调
具体需求：
- 纸张纹理：✅ 有（内联SVG噪点，透明度15%）
- 地图边界：✅ 手绘风格（非标准地图投影）
- 定位标记：✅ 图钉样式（手绘星形，如草图中的★）
- 颜色：✅ 暖色调（米白背景 #F5F0E6 + 苔藓绿 #92A87C）
- 装饰元素：✅ 波浪线连接（参考草图中连接模块的波浪线）

地图表现手法：
- 使用简化的地理轮廓，不追求严格精确
- 重点表达"经历所在地的感觉"
- 地图上的河流、山脉等元素使用手绘线条
- 定位标记（星形）带轻微动画（呼吸效果）
```

#### 【千禧街机阶段 - 像素网格风格】

```
【已填写的方案】
参考风格：复古像素游戏 + CRT显示器效果
具体需求：
- 像素化程度：✅ 中度（边界像素化，核心元素清晰）
- 网格线：✅ 有（淡色网格背景，透明度5%）
- 定位标记：✅ 像素化方块（8-bit风格）
- 颜色：✅ 高对比度荧光色（深蓝背景 #1a1a2e + 荧光绿 #00ffcc）
- CRT效果：✅ 扫描线（密度15px，透明度8%）

地图表现手法：
- 地图轮廓使用块状像素化
- 背景有淡淡的网格线
- 定位标记使用发光的像素方块
- 扫描线覆盖整个地图区域
```

#### 【AI未来阶段 - 科技数据流风格】

```
【已填写的方案】
参考风格：科技感数据可视化 + 霓虹线条
具体需求：
- 数据流动画：✅ 有（粒子流动，速度中等）
- 连线效果：✅ 有（定位点之间有虚线连接）
- 定位标记：✅ 发光圆点（带脉冲动画）
- 颜色：✅ 冷色调科技感（深黑背景 #0a0a0a + 赛博蓝 #00d9ff）
- 霓虹效果：✅ 霓虹线条轮廓（发光效果）

地图表现手法：
- 地图轮廓使用细线条
- 定位点之间有虚线连接（表达"数据流动"）
- 定位标记有呼吸脉冲效果
- 背景有流动的粒子效果
```
