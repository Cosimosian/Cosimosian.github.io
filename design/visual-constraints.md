# 全局视觉一致性约束方案（visual-constraints v1.0）

> **定位**：所有主题设计与调整的唯一约束框架。参考驱动的 v2.0 再设计必须先满足本文档，
> 再谈风格差异化。本文档优先于任何主题设计稿。
>
> **配套**：`scripts/check-contrast.js`（对比度自动校验）、`design/qa-baseline/`（截图基线）。

---

## 1. 五层约束体系

| 层 | 内容 | 职责 |
|---|---|---|
| L0 原则层 | 每主题 3 条设计原则（一句话，不可违背） | 定性准则 |
| L1 令牌层 | `css/tokens.css` = 唯一视觉真相 | 色/字/间距/圆角/阴影/动效全令牌化，组件禁止硬编码 |
| L2 组件层 | 组件只消费令牌 | 布局尺寸由 `specs/responsive.md` 锁定 |
| L3 主题层 | 主题只能覆盖令牌 + 特效层（材质/动效/装饰） | 禁改布局结构 |
| L4 校验层 | 对比度脚本 + QA 截图基线 | 自动/半自动把关 |

---

## 2. 全局统一尺度（跨主题不变，风格只改"皮肤"）

| 维度 | 统一规则 |
|---|---|
| 间距 | 8px 倍数系统（8/12/16/24/32/48），全部主题共用 |
| 圆角 | 四档定义：4/8/12/16px；风格差异靠组合，不引入任意值 |
| 阴影 | 三级 elevation（浅/中/深）；主题可换颜色，层级数统一 |
| 动效 | 三档时长 150/300/800ms；曲线库两条：`ease-out` 与 `cubic-bezier(0.16,1,0.3,1)`（主题只能库内选） |
| 字号 | `--fs-*` 阶梯唯一来源，主题永不改字号 |
| 字距 | 标题 -0.02em ~ +0.05em；正文 -0.01em ~ +0.03em（范围约束） |
| 对比度 | 正文 ≥4.5:1；大字/图标 ≥3:1（所有主题色板必须通过脚本校验） |
| 触控目标 | ≥44×44px（视觉与热区分离） |
| 强调色数量 | 每主题 ≤2 个（accent + secondary） |

---

## 3. 主题差异化白名单

### 主题可改
- 色板值（在对比度约束内）
- 字体族（标题/正文，CDN 或系统栈）
- 字距数值（在范围约束内）
- `--fs-adjust` 视觉大小修正
- 纹理 SVG（--texture-overlay）与密度
- 材质装饰（玻璃高光/贴纸圆角/呼吸动画等，见 L3）
- 动效曲线选择（库内二选一）
- 地图画法（map-style.json 按 role）

### 主题不可改
- 布局尺寸与面板比例
- 间距尺度、圆角档位定义、阴影层级数
- 字号阶梯、组件结构、交互逻辑
- 双端互斥断点（640px）
- 响应式分档（S/M/L/XL/H1/H2）

---

## 4. 视觉 QA 检查清单（每次视觉调整后必过）

1. 每主题 4 屏截图：1920 / 1366 / 390 / 弹窗 → 存入 `design/qa-baseline/`
2. 对比度：`node scripts/check-contrast.js` 全绿
3. 动效降级：`prefers-reduced-motion` 下无动画
4. 字体回退：断网状态下排版不崩（字体栈兜底）
5. 主题切换：无闪烁、无残留
6. 移动端不崩（后续单独优化，但不得回归）

---

## 5. 变更流程

```
改令牌（单维度）→ 跑 check-contrast → 过 QA 清单 → 按维度提交（色/型/材质/动效分开 commit）
```
